# rabotaBot

Полуавтоматический поиск работы и проектов для разработчика: собирает вакансии
из бесплатных публичных источников, отсеивает мусор, ранжирует, пишет черновики
откликов и присылает карточки в Telegram. **Ничего не отправляет сам.**

Живёт на домашнем сервере: **https://yefrix.uk/rabota/**
(`yefrix.duckdns.org` резолвится в тот же адрес и роутер отвечает на оба хоста,
но канонический — `yefrix.uk`)

---

## Что он делает

| Этап | Что происходит |
|---|---|
| 1. Сбор | ~7 семейств коннекторов над публичными ATS/агрегаторами. Новый источник = строка в `config/sources.yaml`. |
| 2. Нормализация | Сырой ответ сохраняется дословно, затем разбирается в канонический `job_posting`. |
| 3. Дедуп | L0 идемпотентность → L1 канонический apply-URL → L2 хэш «компания+должность+страна». Охват агрегаторами (`fan_out`) становится **отрицательным** признаком. |
| 4. Жёсткие отсевы | Гео, таймзона, гибрид, допуск, форма занятости, грейд, вилка, протухло, чёрный список. Каждый отказ с кодом причины. |
| 5. Скоринг | Детерминированный `S_fast`, затем LLM-судья только по верхушке. |
| 6. Черновик | Генерация строго из реестра фактов + детерминированный fact-guard + бан-лист штампов. |
| 7. Человек | Карточка в Telegram. Одобрение чеканит HMAC-токен. Дальше бот останавливается. |
| 8. Трекинг | Машина состояний по заявке, напоминание на 4-5 день, автозакрытие на 10-й. |

Подробное обоснование каждого решения: раздел «Почему так» ниже.

---

## Стек

FastAPI + PostgreSQL 16 + Redis + Celery (worker + beat) + python-telegram-bot +
React/Vite SPA. LLM через локальный Smart AI Gateway (бесплатный, OpenAI-совместимый).

## Запуск локально

```bash
cp .env.example .env      # заполнить POSTGRES_PASSWORD, TELEGRAM_*, LLM_GATEWAY_API_KEY
docker compose up -d --build
docker compose exec rabota-api alembic upgrade head
docker compose exec rabota-api python -m app.cli seed      # источники из config/sources.yaml
```

API: http://localhost:8015/healthz · UI: http://localhost:5186/rabota/

## Деплой на сервер

```bash
cd ~/apps/rabotaBot
git pull
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

Прод-оверлей убирает host-порты, включает Traefik-роутинг на `/rabota` и
`/rabota/api`, гоняет миграции на старте.

## Безопасность

- Приложение **не имеет собственного логина** и обязано стоять за middleware
  `server-auth@file` (ForwardAuth в auth-gateway, 2FA через Telegram).
  Никогда не публикуйте роутеры без него.
- Секреты только в `.env` (gitignored). В репозитории `.env.example`.
- Текст вакансии это недоверенный ввод: он экранируется в UI, изолируется
  тегами в промпте и никогда не исполняется как инструкция (OWASP LLM01).
- Резолвер редиректов защищён от SSRF (только http/https, RFC1918 и
  metadata-эндпоинты заблокированы, максимум 3 перехода).
- Бот принимает команды только от `TELEGRAM_CHAT_ID`.

## Почему так

- **Объём не рычаг.** Массовые автооткликалки дают 0.4-0.6% конверсии против
  рыночных 2-3%. Поэтому `WEEKLY_SEND_CAP` это фича, а не ограничение.
- **Канал решает.** Разброс конверсии между площадками достигает 50x, поэтому
  приоры по источникам байесовские и обновляются на каждой отправке.
- **Отправка не автоматизируется.** Кандидатских credential для сабмита в
  Greenhouse/Lever не существует: apply-эндпоинты требуют ключ работодателя.
  Бот готовит артефакты, отправляет человек.
- **Никакого LinkedIn.** UA §8.2 запрещает боты, скрипты и расширения браузера.
  Инвентарь LinkedIn можно получать только через собственные email-алерты.
- **Никаких прокси и обхода капч.** DMCA §1201: $200-2500 за каждый акт обхода.
